# ชุดของ Haro

ชุดหนึ่งชุดคือโฟลเดอร์หนึ่งโฟลเดอร์ในนี้ simulator อ่านทุกโฟลเดอร์ให้เอง ใส่ชุดใน git แล้วทุกคนที่ `git pull` จะได้ชุดเดียวกัน

```
sim/outfits/
├── party/
│   ├── outfit.json        ต้องมี: บอกสี ลาย และของแต่ง
│   └── party-dots.png     รูปที่ outfit.json ใช้
├── royal/
│   ├── outfit.json
│   └── crown.glb          โมเดล 3 มิติ
├── _blender/
│   └── haro-body.glb      ตัว Haro สำหรับเปิดใน Blender (ไม่ใช่ชุด)
├── check_outfits.py       ตรวจทุกชุดก่อน commit
└── index.json             รายชื่อชุด check_outfits.py เขียนให้ ไม่ต้องแก้เอง
```

โฟลเดอร์ที่ขึ้นต้นด้วย `_` ไม่นับเป็นชุด

ชุดที่มีให้ใช้เป็นตัวอย่างได้ทั้งหมด

| โฟลเดอร์ | ชื่อ | ตัวอย่างของ |
|---|---|---|
| `classic` | คลาสสิก | หน้าตาเดิม ไม่เปลี่ยนอะไร |
| `chick` | ลูกเจี๊ยบ | เปลี่ยนสีทุกส่วนและสีจอ ของแต่งที่ฐาน |
| `kitty` | แมวส้ม | `mirror` ทำของคู่ซ้ายขวา และของแต่งหลายจุดยึด |
| `party` | ปาร์ตี้ | ใส่รูปลายให้ของแต่ง |
| `royal` | มงกุฎทอง | ของแต่งเป็นโมเดล `.glb` |
| `winter` | ชุดกันหนาว | รูปขาวเทารูปเดียว ย้อมได้หลายสีด้วย `color` |
| `watermelon` | แตงโม | ลายเปลือกทั้งตัวที่วาดจากแม่แบบ |

## ไฟล์ที่ใช้ได้

| ไฟล์ | ใช้ทำอะไร | ข้อกำหนด |
|---|---|---|
| `outfit.json` | สี ลาย ของแต่ง | JSON แบบ UTF-8 ใส่ comment ไม่ได้ อยากอธิบายให้ใช้ช่อง `description` |
| `.png` `.jpg` `.webp` | ลายบนเปลือกหรือของแต่ง | ด้านยาวไม่เกิน 2048 px |
| `.glb` | โมเดล 3 มิติ เช่น หมวกที่ปั้นใน Blender | ดูหัวข้อ "โมเดล .glb" |

- ไฟล์ละไม่ควรเกิน 2 MB รับสูงสุด 5 MB เพราะทุกคนต้องโหลดตอน clone
- ชื่อโฟลเดอร์: ภาษาอังกฤษตัวเล็ก ตัวเลข `-` `_` เช่น `pink-bunny`
- ชื่อไฟล์: ภาษาอังกฤษ ตัวเลข `-` `_` `.` และเขียนใน `outfit.json` ให้ตรงทุกตัวอักษร รวมตัวเล็กตัวใหญ่ (บน Windows ผิดก็ยังเปิดได้ แต่เครื่องอื่นจะหาไม่เจอ)

## ทำชุดใหม่

1. copy โฟลเดอร์ชุดที่ใกล้กับที่อยากได้ที่สุด แล้วตั้งชื่อใหม่ เช่น copy `kitty` เป็น `pink-bunny`
2. แก้ `outfit.json` ด้วย VS Code หรือ Notepad อย่างน้อยเปลี่ยน `name` กับ `author` ลบไฟล์รูปที่ไม่ใช้ออก
3. เปิด simulator กด **เปลี่ยนชุด** (หรือ O) แล้วกด **โหลดรายการใหม่** ชุดใหม่จะขึ้นในตู้ แก้ไฟล์แล้วกดปุ่มนี้อีกครั้งเพื่อดูผล ไม่ต้องรีเฟรชหน้า ถ้ามีอะไรผิด จะขึ้นคำเตือนสีส้มใต้ชื่อชุด
4. ตรวจก่อน commit ต้องไม่มีบรรทัด `FAIL`
   ```
   python sim/outfits/check_outfits.py
   ```
5. commit แล้ว push
   ```
   git add sim/outfits/pink-bunny sim/outfits/index.json
   git commit -m "Add pink-bunny outfit"
   git push
   ```
   คนอื่น `git pull` แล้วกด **โหลดรายการใหม่** ก็ได้ชุดเดียวกัน

**ลองโดยยังไม่ใส่ใน repo:** กด **ลองชุดจากโฟลเดอร์** แล้วเลือกโฟลเดอร์ชุด หรือลากโฟลเดอร์มาวางบนหน้า simulator เช่น ชุดที่เพื่อนส่งมาทางแชต ชุดแบบนี้จะหายเมื่อรีเฟรชหน้า

**ส่งชุดให้เพื่อนดู:** ตอนใส่ชุดจาก repo URL จะมี `?outfit=ชื่อโฟลเดอร์` ต่อท้าย ส่งลิงก์นั้นไป คนที่มีชุดเดียวกันในเครื่องจะเปิดมาเจอชุดนั้นเลย

## ตัวอย่าง

กระต่ายชมพู หูยาวสองข้าง ตาสีชมพู

```json
{
  "format": "haro-outfit/1",
  "name": "กระต่ายชมพู",
  "author": "ชื่อคุณ",
  "description": "หูยาวสองข้าง",
  "body": {
    "shell": { "color": "#ffd1dc", "roughness": 0.8 },
    "wings": { "color": "#ffffff" }
  },
  "screen": { "eye": "#ff4d8d" },
  "hide": ["leaves"],
  "parts": [
    { "name": "หู", "at": "head", "shape": "capsule", "size": [0.45, 2.2],
      "pos": [0.8, 0.9, 0], "rot": [0, 0, -15], "color": "#ffd1dc", "mirror": true }
  ]
}
```

ทุกช่องไม่บังคับ ยกเว้น `format` กับ `name` ช่องที่ไม่ใส่จะใช้หน้าตาเดิมของ Haro

## รายละเอียดแต่ละช่อง

### ข้อมูลชุด

| ช่อง | ความหมาย |
|---|---|
| `format` | ต้องเป็น `"haro-outfit/1"` |
| `name` | ชื่อที่แสดงในตู้เสื้อผ้า |
| `author` | คนทำ |
| `description` | อธิบายชุด |
| `credits` | ที่มาและสัญญาอนุญาตของรูปหรือโมเดลที่ไม่ได้ทำเอง |
| `body` | สีและลายของตัวหุ่น |
| `screen` | สีหน้าบนจอ |
| `hide` | ซ่อนบางส่วนของตัวหุ่น |
| `parts` | ของแต่ง |

### `body`: สีและลายของตัวหุ่น

ส่วนที่เปลี่ยนได้

| ส่วน | คืออะไร |
|---|---|
| `shell` | เปลือกรูปไข่ |
| `wings` | ปีกเล็กสองข้าง |
| `leaves` | ขนสามเส้นบนหัว (เรืองแสงสีฟ้าอยู่แล้ว) |
| `base` | ฐานที่มีเซอร์โวอยู่ข้างใน |
| `ring` | วงแหวนรอบฐาน (เรืองแสงสีฟ้าอยู่แล้ว) |
| `bezel` | ขอบจอและขอบกล้อง |

แต่ละส่วน (และของแต่งใน `parts`) ใส่ช่องเหล่านี้ได้

| ช่อง | ค่า | ความหมาย |
|---|---|---|
| `color` | `"#ff8800"` | สี ถ้าใส่คู่กับ `texture` รูปจะถูกย้อมด้วยสีนี้ ถ้าไม่ใส่ รูปแสดงสีจริง |
| `texture` | `"ชื่อไฟล์.png"` | รูปลาย |
| `repeat` | `[4, 2]` | ให้ลายซ้ำกี่รอบ แนวนอนกับแนวตั้ง |
| `roughness` | 0 ถึง 1 | 0 = มันเงาเหมือนพลาสติกขัด 1 = ด้านเหมือนผ้า |
| `metalness` | 0 ถึง 1 | 1 = โลหะ |
| `glow` | `"#ff8800"` | สีเรืองแสง ใส่ `"#000000"` เพื่อไม่ให้เรือง (เช่น ขนบนหัวสีอื่นที่ไม่อยากให้มีแสงฟ้าปน) |
| `glowStrength` | 0 ถึง 3 | ความแรงของการเรือง ตั้งต้น 0.6 |

### `screen`: สีหน้าบนจอ

| ช่อง | ใช้กับ | ค่าเดิม |
|---|---|---|
| `background` | พื้นจอ | `#182224` |
| `eye` | ตา ปาก และ zzz | `#8fe3ea` |
| `highlight` | จุดประกายในตา | `#f0fafa` |
| `blush` | แก้มแดงตอนถูกลูบ | `#e27896` |

ตอนนี้มีผลแค่ใน simulator (`haro.py` ยังไม่อ่านไฟล์ชุด) แต่เป็นสีที่จอ GC9A01 จริงแสดงได้

### `hide`: ซ่อนบางส่วน

ซ่อนได้ `"wings"`, `"leaves"`, `"ring"` เช่น `"hide": ["leaves"]` ตอนใส่หมวก ซ่อนปีกแล้วฟอยล์ข้างตัวยังอยู่ ลูบข้างตัวได้เหมือนเดิม

### `parts`: ของแต่ง

ใส่ได้ไม่เกิน 64 ชิ้น แต่ละชิ้นต้องมี `shape` หรือ `model` อย่างใดอย่างหนึ่ง

| ช่อง | ความหมาย |
|---|---|
| `name` | ชื่อชิ้น ใช้ในคำเตือน |
| `at` | จุดยึด (ตารางข้างล่าง) ไม่ใส่ = `body` |
| `shape` | รูปทรง (ตารางข้างล่าง) |
| `size` | ขนาด หน่วยเป็นเซนติเมตร |
| `model` | ไฟล์ `.glb` ใช้แทน `shape` |
| `pos` | `[x, y, z]` ระยะจากจุดยึด หน่วยเป็นเซนติเมตร |
| `rot` | `[x, y, z]` หมุนรอบแกน x y z หน่วยเป็นองศา |
| `scale` | ตัวเลขเดียว = ขยายทุกทาง หรือ `[x, y, z]` = ยืดหรือบีบแต่ละแกน เช่น `[1, 1, 0.5]` ทำให้แบน |
| `mirror` | `true` = ทำอีกชิ้นที่ฝั่งตรงข้าม (กลับซ้ายขวา) ใช้กับหู ปีก หนวด |
| `opacity` | 0 ถึง 1 ความทึบ ไม่เกิน 0.5 ถือว่าใส กล้องมองทะลุได้ |
| `color` และช่องอื่นของ `body` | เหมือนใน `body` ไม่ใส่สี = สีขาว |

รูปทรง

| `shape` | `size` | หมายเหตุ |
|---|---|---|
| `box` | `[กว้าง, สูง, ลึก]` | |
| `sphere` | `รัศมี` หรือ `[รัศมี, องศา]` | องศา = คลุมลงมาจากด้านบนกี่องศา 90 = ครึ่งลูกแบบหมวก 180 = เต็มลูก |
| `cylinder` | `[รัศมี, สูง]` หรือ `[รัศมีบน, รัศมีล่าง, สูง]` | ตั้งตามแกน y |
| `cone` | `[รัศมีฐาน, สูง]` | ปลายแหลมชี้ขึ้น |
| `torus` | `[รัศมีวง, รัศมีท่อ]` หรือ `[รัศมีวง, รัศมีท่อ, องศา]` | วงตั้งหันหน้าออก ใส่ `"rot": [90, 0, 0]` ให้นอนพันรอบตัว (ผ้าพันคอ) องศา 180 = ครึ่งวง (ที่คาดผม) |
| `capsule` | `[รัศมี, ความยาวส่วนตรง]` | ตั้งตามแกน y |

ทุกรูปทรงมีจุดกลางอยู่ตรงกลางชิ้น ขนาดแต่ละค่าอยู่ระหว่าง 0.01 ถึง 40 ซม.

### แกนและจุดยึด

- **x บวก** = ด้านซ้ายของ Haro (ขวามือของคนที่นั่งหน้า Haro)
- **y บวก** = ขึ้น
- **z บวก** = ด้านหน้า ทางที่จอหัน

| `at` | อยู่ตรงไหน | ตำแหน่งบนตัว (x, y, z) ซม. |
|---|---|---|
| `head` | ยอดหัว | (0, 6.95, 0) |
| `face` | กลางจอ ที่ผิวหน้าจอ | (0, 2.95, 3.45) |
| `body` | ก้นตัว ตรงที่ตัวนั่งบนฐาน | (0, 0, 0) |
| `back` | กลางหลัง ตรงที่ตัวกว้างที่สุด | (0, 2.35, −3.3) |
| `left` | กลางปีกซ้ายของ Haro | (3.2, 2.5, −0.2) |
| `right` | กลางปีกขวาของ Haro | (−3.2, 2.5, −0.2) |
| `base` | พื้นโต๊ะใต้กลางฐาน | ไม่หมุนตามตัว |

ทุกจุดยึดหมุนไปพร้อมตัว Haro ยกเว้น `base` ใช้ `base` กับของที่วางบนโต๊ะหรือติดฐาน เช่น เท้าของ `chick`

### ขนาดของ Haro

ใช้กะขนาดของแต่ง และใช้ตอนทำชุดจริงให้ตัวหุ่น

| ส่วน | ขนาด |
|---|---|
| ทั้งตัว | สูงประมาณ 12 ซม. จากโต๊ะ ไม่รวมขนบนหัว |
| ตัว (ส่วนที่หมุน) | สูง 6.95 ซม. กว้างที่สุด 6.6 ซม. ที่ความสูง 2.35 ซม. ก้นตัวกว้าง 4.1 ซม. |
| จอ | ภาพกว้าง 3.24 ซม. ขอบจอกว้าง 4.0 ซม. ศูนย์กลางสูง 2.95 ซม. |
| กล้อง | สูง 5.4 ซม. ด้านหน้า เงยขึ้น 10° มองเห็นกว้าง 61° สูง 48° |
| ฟอยล์ (จุดลูบ) | บนหัวที่สูงกว่า 4.6 ซม. และด้านข้างที่ห่างจากแกนกลางเกิน 1.6 ซม. |
| ฐาน | สูง 4.8 ซม. รัศมี 4.25 ซม. |

ความสูงทุกค่าวัดจากก้นตัว ยกเว้นฐาน

## ลายเปลือก

กด **แม่แบบลายเปลือก** ในตู้เสื้อผ้า จะได้รูป `haro-skin-template.png` ขนาด 1024 × 512 ที่บอกว่าแต่ละส่วนของรูปไปอยู่ตรงไหนบนตัว

- รูปนี้ห่อรอบเปลือกทั้งใบ ด้านบนของรูป = ยอดหัว แถบเทาล่างสุดอยู่ใต้ตัว มองไม่เห็น
- กลางรูป = ด้านหน้า ขอบซ้ายและขวาต่อกันที่กลางหลัง ลายที่ขอบซ้ายควรต่อกับขอบขวาได้พอดี
- ช่องสีเข้มตรงกลาง = จอ ลายตรงนั้นถูกขอบจอบัง วงแดง = กล้อง ห้ามวาดอะไรนูนทับ
- สีฟ้า = ฟอยล์ที่ใช้ลูบ
- ยิ่งใกล้ขอบบนของรูป ลายยิ่งหดเล็กลงบนตัว เพราะรอบหัวตรงนั้นเล็ก

วิธีทำ: เปิดแม่แบบในโปรแกรมวาดรูปที่มีเลเยอร์ (Krita, GIMP, Photopea) วาดลายในเลเยอร์ใหม่ ซ่อนเลเยอร์แม่แบบ export เป็น PNG ขนาดเท่าเดิม แล้วใส่

```json
"body": { "shell": { "texture": "my-skin.png" } }
```

ดูตัวอย่างใน `watermelon/` ถ้าอยากรู้ว่าวาดตรงไหนแล้วไปโผล่ตรงไหน ลองใส่ไฟล์แม่แบบเป็น `texture` ตรงๆ ก่อน

**วาดบนตัว 3 มิติใน Blender แทนได้** ชิ้น `shell` ใน `_blender/haro-body.glb` ห่อรูปแบบเดียวกับ simulator ทุกจุด เลือก `shell` เข้าโหมด Texture Paint เพิ่มรูป Base Color ขนาด 1024 × 512 วาดลงบนตัวได้เลย แล้วบันทึกรูปเป็น PNG (Image > Save As) ไฟล์นั้นใช้เป็น `texture` ของ `shell` ได้ทันที

## ตรวจชุด

ใต้ชื่อชุดในตู้เสื้อผ้าจะบอก

- **ชุดบังกล้อง %** ส่วนของภาพกล้องที่ของแต่งบัง ถ้าบังตรงที่หน้าเจ้าของอยู่ Haro จะหาหน้าไม่เจอจริง ภาพจากกล้อง Haro จะขึ้นว่า "ชุดบังกล้อง" ควรเป็น 0%
- **บังจอ %** ส่วนของจอที่ถูกบังเมื่อมองจากระดับตาเจ้าของ ควรเป็น 0%
- **คำเตือนสีส้ม** เช่น สะกดชื่อช่องผิด หาไฟล์ไม่เจอ ค่าใช้ไม่ได้ ส่วนที่ผิดจะถูกข้าม ส่วนอื่นยังแสดงตามปกติ

กดโดนของแต่งบนหัวจะทะลุไปโดนฟอยล์ข้างใต้ เหมือนลูบผ่านผ้าบาง แต่ของจริง ถ้าชุดทับฟอยล์ด้วยวัสดุหนาหรือพลาสติกแข็ง touch sensor อาจลูบไม่ติด ควรลองกับตัวจริงก่อน

## โมเดล .glb

ใช้กับของแต่งที่ต่อจากรูปทรงพื้นฐานไม่ได้ เช่น มงกุฎใน `royal/` ใส่ใน `parts` ด้วย `"model"` แทน `"shape"`

```json
{ "name": "หมวก", "model": "hat.glb", "at": "body" }
```

### ปั้นใน Blender ให้พอดีตัว Haro

1. ใน Blender กด File > Import > glTF 2.0 แล้วเลือก `sim/outfits/_blender/haro-body.glb` (หรือกดปุ่ม **ตัว Haro สำหรับ Blender** ในตู้เสื้อผ้าเพื่อดาวน์โหลดไฟล์เดียวกัน)
2. ในไฟล์นี้ 1 หน่วย = 1 ซม. Blender จะแสดงเป็นเมตร เช่น ตัวสูง 6.95 m ให้อ่านเป็น 6.95 ซม. ไม่ต้องแปลงหน่วย
3. จุด (0, 0, 0) คือก้นตัว Haro ตรงกับจุดยึด `body` หน้าจอหันไปทาง −Y ของ Blender กด 1 บน numpad เพื่อมองจากด้านหน้า
4. ในไฟล์มีของช่วยดูด้วย
   - `touch_pad_crown`, `touch_pad_left`, `touch_pad_right` สีฟ้าใส คือฟอยล์ที่ใช้ลูบ อย่าเอาของหนาทับ
   - `camera_view_keep_clear` สีแดงใส คือส่วนที่กล้องมองเห็น ของแต่งห้ามล้ำเข้าไป
   - `anchor_head`, `anchor_face` และอื่นๆ (Empty) คือจุดยึดทั้ง 7 จุด
5. ปั้นของแต่งตรงตำแหน่งที่จะใส่บนตัวเลย
6. เลือกเฉพาะชิ้นของแต่ง แล้วกด File > Export > glTF 2.0 ตั้ง Format เป็น glTF Binary (.glb) ติ๊ก Include > Limit to > Selected Objects ส่วน Transform > +Y Up เปิดไว้ตามเดิม และอย่าเปิด Compression
7. ใส่ไฟล์ในโฟลเดอร์ชุด แล้วใส่ `{ "model": "ชื่อไฟล์.glb", "at": "body" }` ไม่ต้องตั้ง `pos` หรือ `scale` เพราะปั้นไว้ในตำแหน่งจริงแล้ว

### กฎของไฟล์ .glb

- ใช้สีและลายที่อยู่ในไฟล์ ไม่ใช้ `color`, `texture` หรือ `opacity` ใน `outfit.json`
- จุดกำเนิดของโมเดลจะวางตรงจุดยึด ใช้ `pos`, `rot`, `scale`, `mirror` ขยับต่อได้เหมือนรูปทรงพื้นฐาน
- ใช้ได้แค่ `.glb` ไฟล์เดียว ไม่รับ `.gltf` ที่แยกไฟล์ `.bin` หรือรูปไว้ข้างนอก และไม่รับไฟล์ที่บีบอัดแบบ Draco
- โมเดลจะอยู่นิ่ง animation ในไฟล์ไม่เล่น
- โมเดลที่โหลดจากเว็บ เช่น Kenney หรือ Quaternius (CC0) หรือ Poly Pizza (ดูสัญญาอนุญาตทีละชิ้น) ส่วนมากใช้หน่วยเมตร ให้ import เข้า Blender คู่กับ `haro-body.glb` ย่อขยายและวางให้พอดีก่อน แล้วค่อย export ตามข้อ 6 อย่าลืมใส่ที่มาใน `credits`

ถ้าแก้รูปร่างตัว Haro ใน `sim/main.js` ให้กดปุ่ม **ตัว Haro สำหรับ Blender** แล้วเอาไฟล์ที่ได้ไปทับ `_blender/haro-body.glb`

## ข้อตกลงของทีม

- อย่าแก้ชุดของคนอื่นโดยไม่บอกก่อน ถ้าอยากได้แบบอื่น ให้ทำชุดใหม่
- ใช้รูปและโมเดลที่ทำเอง หรือที่อนุญาตให้ใช้ (CC0, CC-BY) เท่านั้น ใส่ที่มาใน `credits`
- รัน `check_outfits.py` ก่อน push ทุกครั้ง

## ปัญหาที่พบบ่อย

| อาการ | ลองดู |
|---|---|
| ชุดใหม่ไม่ขึ้นในตู้ | กด **โหลดรายการใหม่** และเปิด simulator ผ่าน `run_sim.bat` |
| ชุดขึ้นเป็นสีส้ม กดไม่ได้ | ชี้เมาส์ค้างที่ชุดจะบอกสาเหตุ ส่วนมากเป็นชื่อโฟลเดอร์ที่มีตัวใหญ่หรือเว้นวรรค หรือ JSON ผิด เช่น ลืม `,` หรือมี `,` เกินหลังตัวสุดท้าย รัน `check_outfits.py` จะบอกบรรทัด |
| ลายไม่ขึ้น | ชื่อไฟล์ใน `outfit.json` ตรงกับชื่อจริงทุกตัวอักษรไหม ไฟล์อยู่ในโฟลเดอร์ชุดเดียวกันไหม |
| ลายสีเพี้ยน | ใส่ `color` ไว้ด้วย รูปจึงถูกย้อม ลบ `color` ออก |
| ของแต่งหายเข้าไปในตัว | ตำแหน่งอยู่ในเปลือก ขยับ `pos` ออกมา ดูตาราง "ขนาดของ Haro" |
| โมเดล `.glb` ไม่ขึ้น หรือเล็ก/ใหญ่ผิดปกติ | โมเดลใช้หน่วยเมตร ให้จัดขนาดใน Blender คู่กับ `haro-body.glb` ตามหัวข้อ "โมเดล .glb" ถ้ามีคำเตือนว่าเปิดไม่ได้ ดูว่า export แบบ Draco หรือเป็น `.gltf` หรือเปล่า |
| แก้ไฟล์แล้วไม่เปลี่ยน | กด **โหลดรายการใหม่** |
