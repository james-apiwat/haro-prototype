# เสียงสำหรับทดสอบการลูบ

ทุกไฟล์ในโฟลเดอร์นี้ **ไม่ได้ใช้เทรนโมเดล** จึงเป็นการทดสอบจริงว่า Haro แยกเสียงที่ไม่เคยได้ยินได้ไหม ที่มาและ license (CC0) อยู่ใน `dataset/petting/SOURCES.md`

| ไฟล์ | เสียง | Haro ควรทำ |
|---|---|---|
| `demo_sequence.wav` | รวมทุกแบบต่อกัน 61 วินาที (ดูลำดับข้างล่าง) | ดีใจเฉพาะช่วงลูบและเกา |
| `stroke_fur.wav` | ลูบขนยาว 13 วินาที | ดีใจ ประเภท `stroke` |
| `scratch_blanket.wav` | เกาผ้าห่ม 20 วินาที | ดีใจ ประเภท `scratch` |
| `normal_typing.wav` | พิมพ์คีย์บอร์ด 20 วินาที | ไม่ดีใจ |
| `normal_talking.wav` | คนคุยกัน 20 วินาที | ไม่ดีใจ (อาจเอียงคอสงสัย เพราะได้ยินเสียงพูด) |

ลำดับใน `demo_sequence.wav`

| วินาที | เสียง |
|---|---|
| 0–3 | เงียบ |
| 3–16 | ลูบขน |
| 16–20 | เงียบ |
| 20–30 | พิมพ์คีย์บอร์ด |
| 30–33 | เงียบ |
| 33–43 | คนคุยกัน |
| 43–46 | เงียบ |
| 46–58 | เกาผ้าห่ม |
| 58–61 | เงียบ |

## วิธีทดสอบ

**แบบไม่ใช้ไมค์** (เช็คว่าโมเดลแยกเสียงได้ไหม)

```
.venv\Scripts\python pet_audio.py check test_sounds\demo_sequence.wav
```

**แบบเปิดให้ Haro ฟัง** (เช็คทั้งระบบ รวมลำโพงและไมค์)

1. เปิด Haro ด้วย `run_haro.bat` แล้วกด I
2. เปิดไฟล์เสียงจาก**มือถือ** แล้วถือลำโพงมือถือไว้ใกล้ไมค์โน้ตบุ๊ก (มักอยู่ขอบบนจอข้างกล้อง) ห่างประมาณ 10–20 ซม. เสียงดังปานกลาง
3. ดูบรรทัด `pet-audio` ช่วงลูบควรขึ้น `PETTING` และ Haro ตายิ้มแก้มแดงค้างไว้จนเสียงลูบหยุด

ถ้าเปิดจากลำโพงของโน้ตบุ๊กเครื่องเดียวกัน Windows อาจตัดเสียงที่ลำโพงตัวเองเล่นออกจากไมค์ ผลจะเพี้ยน ใช้มือถือหรือลำโพงอื่นดีกว่า
