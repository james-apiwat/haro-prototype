# Haro body firmware (ESP32-S3)

ESP32 ทำหน้าที่เป็น "ร่างกาย" อย่างเดียว สมองทั้งหมดยังอยู่ใน `haro.py` บนคอม

- รับคำสั่งจากคอมผ่านสาย USB แล้วขยับคอ (เซอร์โว 2 ตัว) และวาดตาบนจอกลม GC9A01
- ส่ง `T` กลับไปเมื่อมีคนแตะ touch sensor
- ถ้ายังไม่ได้ต่อคอม ตาจะกะพริบและหายใจเองอยู่แล้ว ใช้เช็กว่าจอทำงาน

โค้ดอยู่ที่ `haro_body/haro_body.ino` ไฟล์เดียว

## สถานะ

- คอมไพล์ผ่านแล้วสำหรับ ESP32-S3 (esp32 core 3.3.12, GFX Library for Arduino 1.6.9, ESP32Servo 3.2.1)
- **ยังไม่ได้ทดสอบกับฮาร์ดแวร์จริง** ต้องเช็กขาและทิศเซอร์โวตอนประกอบ

## ต่อสาย

| อุปกรณ์ | ขาอุปกรณ์ | ต่อที่ |
|---|---|---|
| จอ GC9A01 | VCC | 3V3 |
| | GND | GND |
| | SCL (SCK) | GPIO 47 |
| | SDA (MOSI) | GPIO 21 |
| | CS | GPIO 14 |
| | DC | GPIO 41 |
| | RST | GPIO 42 |
| | BL | 3V3 (ถ้าอยากคุมไฟจอ ให้ต่อเข้าขาว่างแล้วแก้ `TFT_BL`) |
| เซอร์โวหันซ้ายขวา (pan) | สายสัญญาณ (ส้มหรือเหลือง) | GPIO 1 |
| เซอร์โวเอียงคอ (roll) | สายสัญญาณ | GPIO 2 |
| เซอร์โวทั้งสองตัว | สายแดง (+) | **5V จากแหล่งจ่ายแยก** |
| | สายน้ำตาลหรือดำ (-) | GND ของแหล่งจ่ายแยก และ **ต่อร่วมกับ GND ของ ESP32** |
| TTP223 | VCC | 3V3 |
| | GND | GND |
| | SIG (I/O) | GPIO 40 |

**ก่อนต่อสายต้องเช็ก 4 เรื่องนี้**

1. **ขาของบอร์ด** เปิด pinout ของบอร์ดที่ซื้อมาเทียบก่อน บอร์ด ESP32-S3 ที่มีกล้องใช้ขา 4 ถึง 18 ไปกับกล้อง ขาในตารางเลือกให้ไม่ชนกับกล้องของบอร์ดแบบที่พบบ่อย (ESP32-S3 WROOM CAM) และห้ามใช้ขา 35, 36, 37 ถ้าบอร์ดมี PSRAM แบบ OPI (รุ่น N8R8, N16R8) ถ้าบอร์ดมีช่อง SD card จะใช้ขา 38, 39, 40 ร่วมด้วย ห้ามเสียบ SD card ระหว่างใช้ หรือย้าย touch ไปขาอื่นแล้วแก้ `PIN_TOUCH`
2. **เซอร์โวต้องเป็นแบบ 180°** (เช่น MG90S หรือ SG90 รุ่นธรรมดา) เพราะต้องสั่งให้ค้างที่มุมได้ เซอร์โวที่เขียนว่า "360°" (เช่น MG996R 360) หมุนต่อเนื่องเหมือนมอเตอร์ สั่งมุมไม่ได้ ใช้ทำคอไม่ได้
3. **ห้ามจ่ายไฟเซอร์โวจากบอร์ด** เซอร์โวกินกระแสกระชากสูง บอร์ดจะรีเซ็ตเองหรือพอร์ต USB ของคอมตัด ใช้แหล่งจ่าย 5V อย่างน้อย 2A แยก แล้วต่อ GND ร่วมกับบอร์ด
4. **TTP223** ใช้โหมดปกติ (ไม่บัดกรีจัมเปอร์ A, B) แตะแล้วขา SIG เป็น HIGH

## แฟลชลงบอร์ด (Arduino IDE 2)

1. Boards Manager ค้น `esp32` ติดตั้ง **esp32 by Espressif Systems** เวอร์ชัน 3.x
2. Library Manager ติดตั้ง **GFX Library for Arduino** (by Moon On Our Nation) และ **ESP32Servo** (by Kevin Harrington)
3. เปิด `haro_body/haro_body.ino`
4. เมนู Tools
   - Board: **ESP32S3 Dev Module**
   - PSRAM: **OPI PSRAM** ถ้าบอร์ดเป็น N8R8 หรือ N16R8 (ไม่มี PSRAM ให้เลือก Disabled ก็ใช้ได้)
   - USB CDC On Boot: **Enabled** ถ้าเสียบสายที่พอร์ตที่เขียนว่า USB (ต่อเข้าชิปตรง) ถ้าเสียบพอร์ตที่เขียนว่า UART หรือ COM ให้เลือก Disabled
   - Port: พอร์ตของบอร์ด
5. กด Upload ถ้าอัปโหลดไม่ขึ้น ให้กดปุ่ม BOOT ค้างไว้ กด RST หนึ่งครั้ง แล้วปล่อย BOOT แล้วอัปโหลดใหม่

## ทดสอบโดยไม่ต้องใช้ haro.py

เปิด Serial Monitor ตั้ง **115200 baud** และ line ending เป็น **Newline** กด RST ที่บอร์ด ต้องเห็น `HARO READY`

| พิมพ์ | ต้องเห็น |
|---|---|
| `?` | บอร์ดตอบ `HARO` |
| `E happy` | ตายิ้ม แก้มแดง |
| `E sleep` | ตาปิด มี z ลอย |
| `E wink` | ขยิบตาข้างขวา |
| `H 20 0` | หัวค่อยๆ หันไปทางหนึ่ง ตาเลื่อนตาม |
| `H -20 0` | หัวหันกลับอีกทาง |
| `H 0 15` | หัวเอียง |
| `H 0 0` | กลับมามองตรง |
| แตะ touch sensor | บอร์ดพิมพ์ `T` |

หน้าตาที่รองรับ: `normal`, `happy`, `sleepy`, `sleep`, `sad`, `surprised`, `wink`

## ปรับเซอร์โวให้ตรงกับตัวหุ่น

ค่าทั้งหมดอยู่ส่วนบนของไฟล์

| ค่า | ใช้ทำอะไร |
|---|---|
| `PAN_CENTER`, `ROLL_CENTER` | มุมเซอร์โวที่หัวมองตรงและตั้งตรง ปรับจนส่ง `H 0 0` แล้วหัวตรง |
| `PAN_DIR`, `ROLL_DIR` | ส่ง `H 20 0` แล้วหัวหันผิดทาง ให้เปลี่ยนเป็น `-1` (`H` บวก = หันไปทางขวาของคนที่นั่งมอง) |
| `PAN_LIMIT`, `ROLL_LIMIT` | มุมสูงสุดจากตรงกลาง ลดลงถ้าหัวไปชนตัว หรือสายจอตึง |
| `MAX_STEP` | ความเร็วหัว ยิ่งน้อยยิ่งนุ่มและเงียบ |

**ก่อนประกอบหัว** ให้แฟลชและปล่อยให้บอร์ดสั่งเซอร์โวไปที่ `CENTER` ก่อน แล้วค่อยใส่แขนเซอร์โวในตำแหน่งที่หัวตรง จะได้ไม่ต้องปรับเยอะ

## ใช้กับ haro.py

1. ปิด Serial Monitor ก่อน (พอร์ตเปิดได้ทีละโปรแกรม)
2. รัน `python haro.py --port COM5` (เปลี่ยนเป็นพอร์ตของบอร์ด บน Mac จะเป็น `/dev/cu.usbmodem...`)
3. ข้อความ `[body] connected COM5` แปลว่าต่อได้ ลองแตะ touch sensor แล้ว Haro บนจอคอมต้องดีใจ

คอมจะส่งท่าทางซ้ำทุก 1 วินาที ถ้าบอร์ดรีเซ็ตตอนเปิดพอร์ตก็จะกลับมาตรงกันเอง เสียงยังเล่นจากลำโพงคอม

## ถ้ามีปัญหา

| อาการ | ลองดู |
|---|---|
| จอดำ | เช็กสาย SCK, MOSI, CS, DC และ BL ต่อ 3V3 แล้วหรือยัง ดู Serial Monitor ว่ามี `display init failed` ไหม |
| จอติดแต่สีเพี้ยนหรือภาพกลับด้าน | แก้ตัวเลขใน `new Arduino_GC9A01(bus, TFT_RST, 0, true)` ตัวที่ 3 คือการหมุนจอ (0 ถึง 3) ตัวที่ 4 คือ IPS (ลอง `false`) |
| บอร์ดรีเซ็ตเองตอนเซอร์โวขยับ | ไฟเซอร์โวไม่พอ ใช้แหล่งจ่ายแยก และต่อ GND ร่วม |
| เซอร์โวสั่นค้าง | มุมเกินที่หัวขยับได้จริง ลด `PAN_LIMIT` หรือ `ROLL_LIMIT` |
| Serial Monitor ไม่ขึ้นอะไรเลย | สลับค่า USB CDC On Boot แล้วแฟลชใหม่ |
| แตะแล้วไม่มี `T` | เช็กขา SIG และไฟ 3V3 ของ TTP223 ไฟ LED บนโมดูลควรติดตอนแตะ |
